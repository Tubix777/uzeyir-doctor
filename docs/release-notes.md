# Uzeyir Doctor v0.1.0

The first standalone release of Uzeyir Doctor includes:

- Local system checks with evidence and suggested next steps.
- Flatpak app and folder-permission checks.
- SSD health details when a recent SMART reading is available.
- Turkish and English interface, a monochrome GTK 4 design, bundled Manrope font and reduced-motion support.
- Fedora RPM, Debian-family DEB and Arch packages, source archive, offline Arch build recipe and SHA256 checksums.

The diagnostic screens are read-only. They do not apply repairs or make up missing device information.
